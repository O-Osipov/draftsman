# Конфигурация

Публичные параметры хранятся в корневом `config.yaml`. Секреты и адрес локального API — в `.env`, который исключён из Git. Образец — `.env.example`. После изменения `config.yaml` или `.env` перезапусти и FastAPI, и бота: настройки FastAPI кэшируются при старте, а отдельный процесс анализа считывает YAML при обработке файла.

## `config.yaml`

| Параметр | Значение по умолчанию | Назначение |
| --- | ---: | --- |
| `dimension_types` | Четыре правила | Регулярные выражения для имён и типы `LINEAR`, `DEPTH`, `DIAMETER`, `CHAMFER`; применяется первое полное совпадение |
| `tolerance_mm` | `0.5` | Допуск каждого нового контрольного размера в миллиметрах; совпадение при `abs(actual - expected) <= tolerance` |
| `max_text_length` | `2000` | Максимум символов текста с размерами |
| `max_dimensions` | `30` | Максимум размеров в одном запросе |
| `max_file_size_mb` | `10` | Предельный размер STL; 1 МБ = 1 048 576 байт; проверяется ботом и API |
| `timeout_sec` | `30` | Время анализа STL до завершения отдельного процесса с кодом `TIMEOUT` |
| `max_concurrent_requests` | `10` | Число одновременно работающих обработчиков FastAPI; остальные ждут свободный слот |
| `report_max_chars` | `4000` | Верхний предел длины готового текста отчёта для Telegram; значение в YAML не может быть больше 4000 |

Числовые ограничения проверяются при загрузке конфигурации: значения должны быть положительными, а `report_max_chars` не может превышать 4000. При ошибке в YAML сервер не запустится; поправь файл и запусти его снова.

Действующие правила имён:

| Имя | Тип | Пример |
| --- | --- | --- |
| `габарит_длина`, `габарит_ширина`, `габарит_высота`, `габарит_диаметр` | `LINEAR` | `габарит_длина=100` |
| `отверстие_N_глубина`, `глубина_N` | `DEPTH` | `отверстие_1_глубина=8` |
| `отверстие_N_диаметр`, `диаметр_N` | `DIAMETER` | `отверстие_1_диаметр=10` |
| `фаска_N` | `CHAMFER` | `фаска_1=2` |

`N` — положительное целое число без начального нуля. Имена приводятся к нижнему регистру. Пары разделяются запятой или переносом строки. Число должно быть больше нуля; дробная часть пишется через точку. Поддерживаются `мм` (по умолчанию), `см`, `дюйм`, `in`, после разбора значения хранятся в мм. Пример: `габарит_ширина=5 см` превращается в `50 мм`. Длина, ширина и высота пластины сопоставляются с X/Y/Z; для вала с `габарит_диаметр` длиной считается наибольший габарит.

Правила в YAML конкретизируют примерные шаблоны из PDF: они принимают только перечисленные имена и различают глубину и диаметр отверстия. Если меняешь шаблоны, проверь, что они совпадают с логикой сопоставления в `backend/comparison.py` и запусти тесты.

## `.env`

| Переменная | Значение | Назначение |
| --- | --- | --- |
| `BOT_TOKEN` | Токен от `@BotFather` | Обязателен для запуска бота; не помещай в Git |
| `API_URL` | `http://127.0.0.1:8000` | Адрес FastAPI для бота, без завершающего `/` |

FastAPI запускается отдельно командой из [README](../README.md). `API_URL` не запускает сервер автоматически; бот и API должны работать одновременно. Папки `.runtime/` и `data/` также исключены из Git.
