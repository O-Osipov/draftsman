# Чертёжник

Telegram-бот для самопроверки 3D-моделей по контрольным размерам с чертежа. В текущей версии бот принимает размеры, проверяет ввод и составляет чек-лист. **Анализ STL и отчёт о расхождениях ещё не реализованы.**

Состояние диалога хранится в памяти и сбрасывается при перезапуске бота. Сервер и база данных для текущей версии не нужны.

## Требования

- Python 3.12 или новее.
- Доступ к интернету из среды запуска.
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather).

## Создать бота и получить токен

1. В Telegram открой `@BotFather` и отправь `/newbot`.
2. Укажи отображаемое имя и уникальное имя пользователя, заканчивающееся на `bot`.
3. Сохрани выданный токен. Он даёт доступ к управлению ботом, поэтому не публикуй его и не добавляй в Git.

Для меню команд можно отправить BotFather команду `/setcommands`, выбрать созданного бота и передать:

```text
start - Приветствие
new - Новый диалог
help - Помощь
cancel - Отменить диалог
```

Меню необязательно: команды работают и без него.

## Установка и запуск

В терминале перейди в папку скачанного проекта и выполни:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Если система сообщает, что `venv` или `ensurepip` недоступен, установи соответствующий системный пакет для своей версии Python и повтори создание `.venv`.

Открой `.env` и замени `PASTE_YOUR_BOT_TOKEN_HERE` на токен BotFather:

```text
BOT_TOKEN=твой_токен_из_BotFather
```

Запусти бота из папки проекта:

```bash
python -m bot
```

Пока эта команда работает и терминал открыт, бот отвечает в Telegram. Остановить его можно сочетанием `Ctrl+C`. Для повторного запуска активируй `.venv` и снова выполни `python -m bot`. Не запускай две копии бота с одним токеном одновременно.

## Проверка в Telegram

1. Открой ссылку на своего бота от BotFather и нажми **Start**. Бот ответит приветствием.
2. Отправь `/new`.
3. Отправь размеры, например:

   ```text
   габарит_длина=100, габарит_ширина=50
   отверстие_1_диаметр=10
   ```

4. Бот покажет чек-лист и сообщит, что размеры сохранены в текущем диалоге.
5. Для проверки ошибки отправь `/new`, затем `габарит_длина=0`. Бот попросит исправить ввод. После этого можно отправить правильные размеры, не начиная диалог снова.
6. `/help` показывает справку, `/cancel` отменяет диалог, `/start` сбрасывает его и показывает приветствие.

Если бот не отвечает, проверь открытый терминал, интернет, токен в `.env` и имя бота в Telegram. Ошибки запуска видны в терминале.

## Формат размеров

Один размер записывается как `название=значение`. Несколько размеров разделяются запятыми или переносами строк. Поддерживаемые названия:

- `габарит_длина`, `габарит_ширина`, `габарит_высота`;
- `отверстие_1_диаметр`, `отверстие_1_глубина` — вместо `1` можно указать другой положительный номер;
- `фаска_1` — номер также можно менять.

Допустимы положительные числа с точкой в дробной части: `10`, `10.5`, `.5`. Единицы: `мм` по умолчанию, `см`, `дюйм` или `in`. Пример: `габарит_длина=10 см`. Внутри бота все значения переводятся в миллиметры. В одном сообщении допускается до 2000 символов и до 30 уникальных размеров. При ошибке сообщение отклоняется целиком и бот ждёт исправленный ввод.

## Локальные тесты

```bash
python -m unittest discover -s tests -v
```

Тесты не требуют токена или подключения к Telegram.

## Структура проекта

```text
bot/
  __main__.py    запуск бота
  config.py      загрузка токена из .env
  dimensions.py  разбор размеров и чек-лист
  handlers.py    команды и диалог

tests/           локальные тесты
.env.example     шаблон настроек
requirements.txt зависимости
```

Файл `.env` и виртуальное окружение `.venv` исключены из Git.
