# Чертёжник

Telegram-бот для самопроверки 3D-моделей по контрольным размерам с чертежа. Текущая версия принимает размеры, выдаёт чек-лист и проверяет загруженный STL на формат, непустую замкнутую сетку и размер файла до 10 МБ. **Измерения геометрии и отчёт о расхождениях пока не реализованы.**

## Архитектура текущего этапа

```text
Telegram → бот (aiogram) → HTTP → FastAPI
                                ├── POST /parse-dimensions
                                └── POST /analyze-model (пока только валидация STL)
```

Бот хранит размеры и состояние диалога в памяти, без базы данных. Загруженный STL временно находится в `.runtime/uploads/` и удаляется после проверки, включая случаи ошибки. Содержимое модели и отчёты не сохраняются. Типы размеров и лимиты задаются в `config.yaml`; токен хранится в локальном `.env`.

## Требования и получение токена

Нужны Python 3.12 или новее и доступ к интернету для Telegram-бота. В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot`, задай отображаемое имя и уникальное имя пользователя с окончанием `bot`. Полученный токен храни как пароль и не добавляй в Git.

Для меню команд можно отправить BotFather `/setcommands` и задать `start`, `new`, `help`, `cancel`.

## Установка

В папке скачанного проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Если система сообщает об отсутствии `venv` или `ensurepip`, установи системный пакет для своей версии Python и повтори создание окружения. В `.env` замени `PASTE_YOUR_BOT_TOKEN_HERE` на токен от BotFather. `API_URL` по умолчанию равен `http://127.0.0.1:8000`.

## Запуск

В первом терминале, из папки проекта:

```bash
source .venv/bin/activate
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Во втором терминале, также из папки проекта:

```bash
source .venv/bin/activate
python -m bot
```

Оба процесса должны продолжать работать во время проверки. Остановка — `Ctrl+C` в каждом терминале. API слушает только `localhost`; открывать порт наружу не нужно. Не запускай две копии бота с одним токеном.

## Проверка в Telegram

1. Открой своего бота по ссылке от BotFather и отправь `/start`, затем `/new`.
2. Отправь размеры, например:

   ```text
   габарит_длина=100, габарит_ширина=50
   отверстие_1_диаметр=10
   ```

3. Бот покажет чек-лист и предложит отправить STL. Прикрепи файл как **документ**, а не как изображение.
4. Для корректного замкнутого STL бот сообщит, что файл прошёл проверку и был удалён. Это пока **не подтверждает совпадение размеров** с чертежом.
5. Для повреждённого файла бот вернёт `INVALID_FILE`; для файла больше 10 МБ — `FILE_TOO_LARGE`. Размеры остаются в текущем диалоге, поэтому можно загрузить другой STL без повторного `/new`.
6. `/cancel` отменяет диалог, `/help` показывает подсказки. Если бот не отвечает, проверь оба терминала, интернет, токен и адрес `API_URL`.

## Формат размеров

Пары `название=значение` разделяются запятыми или переносами строк. Поддерживаются `габарит_длина`, `габарит_ширина`, `габарит_высота`, `габарит_диаметр`, `отверстие_1_диаметр`, `отверстие_1_глубина`, `диаметр_1`, `глубина_1`, `фаска_1`; номер может быть другим положительным целым числом. Единицы: `мм` по умолчанию, `см`, `дюйм`, `in`. Для дробной части используй точку.

FastAPI переводит значения в миллиметры. В одном сообщении допускается до 2000 символов и 30 уникальных размеров. Ошибочное сообщение отклоняется целиком с кодом `INVALID_FORMAT`.

## API и тесты

- `POST /parse-dimensions` принимает JSON `{"user_id": 42, "raw_text": "габарит_длина=100"}` и возвращает размеры с чек-листом.
- `POST /analyze-model` принимает `multipart/form-data`: `user_id`, `dimensions` (JSON-строка со списком размеров), `file` (STL). **Промежуточный ответ HTTP 202** содержит `status`, `format`, `size_bytes`, `message`. Итоговый контракт с `report` будет добавлен вместе с геометрическим анализом.
- Ошибки имеют поля `status: error`, `code`, `message`: `INVALID_FORMAT` (400), `INVALID_FILE` (422), `FILE_TOO_LARGE` (413). Коды `TIMEOUT` и `INTERNAL_ERROR` предусмотрены для сбоев и следующих этапов.

Запуск тестов:

```bash
python -m unittest discover -s tests -v
```

Тесты в `tests/test_stl_validation.py` дополнительно используют локальный архив `data/tests.tar.gz`, если он есть; без архива соответствующая проверка пропускается. Папки `data/` и `.runtime/`, а также `.env` и `.venv` исключены из Git.
